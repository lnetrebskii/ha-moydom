# Мой Дом (Электронный город / Дом.ру) для Home Assistant

Интеграция для домофонов приложения «Мой Дом — Электронный город»
(ЭР-Телеком / Дом.ру, `ru.inetra.intercom`).

## Что умеет

- **Камера** на каждый домофон: живое видео H.264 1080p со звуком и снимки.
- **Кнопка «Открыть дверь»** (по одной на подъезд, если у домофона их несколько).
- Вход как в приложении: номер телефона и код из SMS. Пароль не хранится,
  хранятся только токены сессии. Токен обновляется сам, SMS нужна снова
  только если сессия отозвана.

- **Домофон как ONVIF-камера для видеомонитора в квартире.** Монитор,
  который ищет в сети IP-камеры (раздел IPC), находит домофон сам; остаётся
  добавить его в списке монитора. Нужен add-on go2rtc (см. ниже).

## Установка

1. HACS → Custom repositories → этот репозиторий, категория Integration.
2. Перезапустить Home Assistant.
3. Настройки → Устройства и службы → Добавить интеграцию → «Мой Дом».
4. Ввести номер телефона (`79XXXXXXXXX`), затем код из SMS.

## Видеомонитор в квартире (ONVIF)

Мониторы с разделом «IPC» ищут камеры по ONVIF и тянут видео по RTSP, а
декодер у них слабее телефона. Поэтому для монитора интеграция берёт у облака
облегчённый поток 960×528 (`LightStream=1`), без перекодирования.

Что нужно:

1. Add-on **go2rtc** (тот же, что использует Home Assistant для WebRTC) с
   включённой записью в `configuration.yaml`: `go2rtc: url: http://127.0.0.1:1984`.
2. Настройки → «Мой Дом» → Настроить: «Показывать домофоны мониторам как
   ONVIF-камеры» (включено по умолчанию), адрес go2rtc (`http://127.0.0.1:1984`)
   и его RTSP-порт (`8554`).
3. На мониторе: раздел IPC → поиск, выбрать домофон (логин и пароль не нужны),
   добавить его в список зоны и открыть из «Монитор».

Как устроено: интеграция публикует в go2rtc поток `moydom_<id>_light` с
предзагрузкой (иначе go2rtc отвечает на `DESCRIBE` дольше двух секунд, и
монитор отваливается), отвечает на WS-Discovery (UDP 3702) и на ONVIF-запросы
по адресу `/api/moydom/onvif/<id>/…` порта Home Assistant. Эти адреса открыты
без пароля: они только описывают камеру и называют адрес RTSP, как и сам
RTSP-порт go2rtc, который доступен в локальной сети.

Предзагрузка держит облачный поток всё время: около 0,5 Мбит/с постоянно.
Отключить можно в настройках интеграции.

## Как это работает

Приложение общается с `https://myhome.proptech.ru`. Для видео сервер требует
`User-Agent` в формате приложения, иначе отвечает пустым `400`; клиент
(`custom_components/moydom/api.py`) его собирает. Ссылка на поток выдаётся на
каждый просмотр отдельно, поэтому берётся при старте стрима.

## Разработка

```
uv run --no-project --python 3.13 --with pytest --with pytest-asyncio --with aiohttp pytest
uvx ruff check . && uvx ruff format --check .
```

Тесты клиента API не требуют Home Assistant. Config flow, камера и кнопка
проверяются только на живом Home Assistant.
