# Мой Дом (Электронный город / Дом.ру) для Home Assistant

Интеграция для домофонов приложения «Мой Дом — Электронный город»
(ЭР-Телеком / Дом.ру, `ru.inetra.intercom`).

## Что умеет

- **Камера** на каждый домофон: живое видео H.264 1080p со звуком и снимки.
- **Кнопка «Открыть дверь»** (по одной на подъезд, если у домофона их несколько).
- Вход как в приложении: номер телефона и код из SMS. Пароль не хранится,
  хранятся только токены сессии. Токен обновляется сам, SMS нужна снова
  только если сессия отозвана.

## Установка

1. HACS → Custom repositories → этот репозиторий, категория Integration.
2. Перезапустить Home Assistant.
3. Настройки → Устройства и службы → Добавить интеграцию → «Мой Дом».
4. Ввести номер телефона (`79XXXXXXXXX`), затем код из SMS.

## Как это работает

Приложение общается с `https://myhome.proptech.ru`. Для видео сервер требует
`User-Agent` в формате приложения, иначе отвечает пустым `400`; клиент
(`custom_components/moydom/api.py`) его собирает. Ссылка на поток выдаётся на
каждый просмотр отдельно, поэтому берётся при старте стрима.

## Разработка

```
uv run --no-project --python 3.13 --with pytest --with pytest-asyncio --with aiohttp pytest
uvx ruff check . && uvx ruff format --check .
```

Тесты клиента API не требуют Home Assistant. Config flow, камера и кнопка
проверяются только на живом Home Assistant.
